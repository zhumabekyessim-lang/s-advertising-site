# Сайт S-Advertising Company

Одностраничник без сборки и зависимостей: `index.html` — это весь сайт.
Фотографии проектов — в `assets/` (WebP).

Публикуется через GitHub Pages с ветки `main`.

**Как править:** тексты RU — прямо в разметке (`data-i18n`-атрибуты),
переводы KZ/EN — словари `I18N.kz` / `I18N.en` в `<script>` внизу файла.
Телефоны и WhatsApp-ссылки — константа `WA` там же.
Цвета, шрифты и размеры — CSS-переменные в `:root` в начале `<style>`.

**Как посмотреть локально:** открыть `index.html` двойным кликом.
